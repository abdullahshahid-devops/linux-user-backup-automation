# Linux User Management & Backup Automation

A Bash-based Linux administration project that automates common system administration tasks, including user management, group management, disk usage checks, and timestamped backups.

## Project Overview

This project demonstrates practical Linux system administration and Bash scripting skills through an interactive command-line menu. It was developed and tested on Ubuntu Linux.

## Features

- **Current User:** Display the current logged-in user.
- **Disk Usage:** Check root filesystem disk usage.
- **Timestamped Backups:** Create compressed `.tar.gz` backup archives.
- **User Management:** Create users with input validation and duplicate-user checks.
- **Group Management:** Create groups and add users while checking existing groups and memberships.
- **User Deletion:** Delete users through the interactive menu.
- **Login Shell Management:** Modify a user's login shell.
- **Restore Verification:** Verify backup restoration by comparing restored files against the original test data.

## Backup and Restore Verification

The project uses compressed, timestamped backup archives.

Example backup naming format:

```text
backups/backup_YYYYMMDD_HHMMSS.tar.gz
```

A backup can be inspected using:

```bash
tar -tzf backups/backup_YYYYMMDD_HHMMSS.tar.gz
```

To verify a restored test directory against its original:

```bash
diff -r test-data restore-test
```

If the directories match, `diff` returns exit code `0` and prints no differences.

Replace the example archive name with the actual archive generated by your script.

## Safety Notes

- Review user and group changes before executing administrative operations.
- Avoid publishing credentials, sensitive configuration files, or private backup data.
- Keep generated archives and temporary test data out of version control.
- Test backup restoration before relying on backups for recovery.
